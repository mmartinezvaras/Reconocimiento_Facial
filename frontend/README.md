# Reconocimiento facial

Visor local de los registros CSV generados por el sistema de asistencia facial.

## Development server

Desde esta carpeta, instala las dependencias e inicia el servidor:

```bash
npm install
npm start
```

Abre `http://localhost:4200/`. Los archivos CSV se procesan localmente en el navegador y no se suben a ningún servidor.

## Compilar

```bash
npm run build
```
